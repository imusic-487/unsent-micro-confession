## What it does

`main.py` writes one two-part micro-confession to `/output/entry.txt`:
a `To:` line naming who it was meant for, and the unsent message itself,
one line written exactly as it was typed, with no explanation after it.

## Run

```sh
python3 main.py
```

The program writes `/output/entry.txt` (override with the `OUTPUT_PATH`
environment variable). The entry is 135 characters: two lines, the message
121 characters, inside the 1–260 character gate and the 200-character
message limit.

## Entry

```text
To: my sister
i was the one who broke mum's blue vase in 2009 and let you take the blame because i was too scared to tell her it was me
```
